# SY希腊蔚蓝海岸 · 微信小程序

面向中文用户的中高端希腊定制游 / 地接服务小程序。基于《SY希腊蔚蓝海岸-小程序设计文档》v1.0 制作。

- 官网：sy-greece.com
- 设计稿：Ardot 画布（见 `../sy-greece-miniprogram/`）

## 项目结构

```
MpApp/
├── app.js                     # 全局逻辑（品牌、定制师信息）
├── app.json                   # 页面路由、自定义 tabBar 配置
├── app.wxss                   # 设计系统（色彩变量、卡片、按钮）
├── project.config.json        # 微信开发者工具项目配置
├── sitemap.json               # 页面收录规则
├── custom-tab-bar/            # 胶囊式自定义 TabBar（中间「立即联系」凸起）
├── pages/
│   ├── index/                 # P1 首页（7 大模块长滚动）
│   ├── customize/             # P2 私人定制留资页
│   └── profile/               # P3 我的页面
├── assets/images/             # 压缩后的图片素材（约 1.3MB）
│   ├── hero/                  # 首页头图轮播（750x940）
│   ├── route/                 # 甄选路线大卡（750x560）
│   ├── lux/                   # 奢享体验竖卡（600x750）
│   ├── dest/                  # 目的地瓷贴（600x600）
│   └── misc/                  # 定制师头像、微信二维码占位
└── scripts/
    └── compress_images.py     # 素材压缩脚本（Pillow，cover 裁切）
```

## 页面说明

### P1 首页 `pages/index/index`
1. **品牌头图轮播** — 沉浸式圣托里尼大图 + 62% 深海蓝渐变遮罩 + 毛玻璃搜索栏 + 衬线品牌大字 + 轮播指示点
2. **四大金刚** — 悬浮白卡：蔚蓝海岸 / 私人定制 / 专属用车 / 旅行工具（纯 CSS 图标）
3. **甄选路线** — 4 条包价线路大卡（3天雅典 / 5天圣岛 / 7天伯罗奔尼撒 / 9天全遗产），沙金「价格电询·一对一报价」
4. **奢享体验** — 私人包机 / 游艇出海双竖卡，金色「高端定制」角标
5. **精选目的地** — 文明溯源 / 海岛度假双分类，瓷贴 + 文字标签
6. **品牌页脚** — sy-greece.com + 在地团队文案
7. **底部 Tab** — 胶囊式，中间「立即联系」凸起直达转化

### P2 私人定制留资页 `pages/customize/customize`
- 深蓝引导横幅「告诉我你的想法，希腊交给我们」
- 表单：目的地 / 时间 / 天数 / 人数 / 预算 / 主题多选 / 需求描述 / 电话（手机号校验）
- 唯一主 CTA：提交需求 · 免费获取定制方案
- 定制师微信卡片（双通道留资：表单 + 加微信复制 / 二维码预览）

### P3 我的页面 `pages/profile/profile`
- 渐变头部：头像 + 昵称 + 沙金「SY 尊享会员」标 + 数据行（行程 2 / 收藏 12 / 优惠券 3 / 积分 580）
- 服务单元格卡：我的订单 / 我的行程（进行中 1）/ 优惠券
- 资料与帮助卡：常用出行人 / 护照签证 / 联系客服 / 关于我们

## 设计系统

| 角色 | 色值 |
|---|---|
| 爱琴海主蓝 | `#1567A8` |
| 深海蓝 | `#0B3C5D` |
| 页面底 | `#F4F7FA` |
| 卡片白 | `#FFFFFF` |
| 沙金 | `#C6A15B` |
| 正文 | `#16283A` |
| 次要 | `#5B6B7A` / `#8AA3B5` |

卡片圆角 32rpx（16px），阴影深海蓝 8–14% 上浮模糊；按钮/胶囊 24–36px 圆角。

## 使用

1. 微信开发者工具 → 导入项目，选择本目录
2. AppID 使用测试号或替换 `project.config.json` 中的 `appid`
3. 素材重新压缩：`python3 scripts/compress_images.py`（源图在 `../generated-images/`）
