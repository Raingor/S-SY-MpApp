## 页面规划（来自设计文档）

1. **首页**：品牌头图轮播、核心功能入口（蔚蓝海岸 / 私人定制 / 专属用车 / 旅行工具）、甄选路线 4 条大卡、奢享体验双竖卡
2. **私人定制页**：定制需求表单（目的地 / 时间 / 人数 / 预算 / 主题多选）
3. **我的页**：用户信息、我的行程、联系定制师
